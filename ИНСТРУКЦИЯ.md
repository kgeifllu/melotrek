# Мелотрек — инструкция на сегодня (4 дня за раз)

Делай строго по шагам, сверху вниз. Ничего не пропускай.
Весь готовый код уже лежит в архиве `melotrek.zip` — тебе почти ничего не надо печатать.

---

## ШАГ 1. Распаковать проект

1. Скачай файл `melotrek.zip`.
2. Создай на диске C (или где удобно) папку и назови её `projects`.
3. Перемести `melotrek.zip` в папку `projects`.
4. Нажми на архив правой кнопкой → «Извлечь всё…» → «Извлечь».
5. Появится папка `melotrek`. Внутри неё должна быть папка `app` и файл `requirements.txt`.

---

## ШАГ 2. Открыть папку в редакторе и открыть терминал

1. Открой VS Code.
2. Вверху: «File» → «Open Folder…» → выбери папку `melotrek` → «Открыть».
   Слева ты увидишь дерево файлов (app, requirements.txt и т.д.).
3. Вверху нажми «Terminal» → «New Terminal».
   Внизу откроется чёрное/тёмное поле — это терминал. Все команды ниже вводишь туда.

---

## ШАГ 3. Создать виртуальное окружение и установить пакеты

Вставляй команды по одной. После каждой — Enter. Жди, пока закончится, только потом следующую.

1. Создать окружение:
```
python -m venv venv
```

2. Включить окружение:
```
venv\Scripts\activate
```
После этого в начале строки в терминале появится `(venv)`. Если появилось — всё верно.

> Если выскочит красная ошибка про «running scripts is disabled» — введи одну команду:
> ```
> Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
> ```
> нажми `Y` и Enter, потом снова `venv\Scripts\activate`.

3. Установить всё нужное одной командой:
```
pip install -r requirements.txt
```
Подожди 1–2 минуты, пойдёт много текста — это нормально.

---

## ШАГ 4. Запустить сайт

1. Введи команду:
```
uvicorn app.main:app --reload
```
2. Должна появиться строка вроде `Uvicorn running on http://127.0.0.1:8000`.
3. Открой браузер, вставь в адрес:
```
http://127.0.0.1:8000
```
Должна открыться страница с надписью **«Мелотрек работает»**. 🎉

Это значит: сайт, база данных и структура — готовы.

> Чтобы остановить сайт — вернись в терминал и нажми `Ctrl + C`.
> Чтобы запустить снова — команда из пункта 1 этого шага (окружение `(venv)`
> должно быть включено; если нет — снова `venv\Scripts\activate`).

---

## ШАГ 5. Проверить встроенную документацию API

1. При запущенном сайте открой в браузере:
```
http://127.0.0.1:8000/docs
```
2. Увидишь список методов твоего API (это делает FastAPI сам).
   Здесь будут `GET /` и `POST /tracks/search`.

---

## ШАГ 6. Проверить музыкальный API (поиск и запись треков в базу)

> ВАЖНО про Беларусь: если поиск ниже вернёт ошибку или пусто —
> включи VPN и повтори. Внешние сервисы часто блокируются без него.

1. На странице `http://127.0.0.1:8000/docs` найди строку **POST /tracks/search**.
2. Нажми на неё → справа кнопка «Try it out».
3. В поле `query` впиши имя исполнителя, например: `queen`
4. Нажми синюю кнопку «Execute».
5. Ниже, в разделе Response, должен появиться список треков (название, исполнитель).
   Если список есть — музыкальный API и запись в базу работают.

---

## ШАГ 7. Убедиться, что база создалась

1. В дереве файлов слева в VS Code (после запуска сайта) появится файл `melotrek.db`.
   Это твоя база данных. Значит таблицы созданы.
2. (Необязательно) Чтобы заглянуть внутрь — скачай бесплатную программу
   «DB Browser for SQLite», открой в ней `melotrek.db`, увидишь 5 таблиц:
   games, teams, tracks, rounds, answers.

---

## ШАГ 8. Залить проект на GitHub

1. Останови сайт (`Ctrl + C` в терминале).
2. Если у тебя ещё нет аккаунта — зарегистрируйся на github.com.
3. По очереди введи команды в терминал (каждую — Enter):
```
git init
git add .
git commit -m "Мелотрек: каркас, база данных, музыкальный API"
```
4. Зайди на github.com → нажми зелёную кнопку «New» (новый репозиторий) →
   имя `melotrek` → «Create repository».
5. На открывшейся странице GitHub покажет блок «…or push an existing repository».
   Скопируй оттуда две строки (они начинаются с `git remote add origin…`
   и `git push…`) и вставь в терминал, нажми Enter.
6. Обнови страницу репозитория на GitHub — твои файлы там. Готово.

## Что делать, если застряла

- Красная ошибка при `activate` → см. подсказку в ШАГЕ 3, пункт 2.
- `python` не распознаётся → закрой и открой VS Code заново; либо Python
  не в PATH (тогда переустанови Python с галочкой «Add to PATH»).
- Поиск треков пустой / ошибка → включи VPN, повтори ШАГ 6.
- Сайт не открывается → проверь, что в терминале нет ошибки и есть строка
  «Uvicorn running»; адрес именно `http://127.0.0.1:8000`.
