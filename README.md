# Мелотрек

Веб-приложение — автоматический движок музыкальных квизов формата «угадай трек».
Разработано на Python в рамках вычислительной практики.

## Возможности

- Создание игры и команд (полный CRUD: получение, создание, изменение, удаление)
- Подбор треков через внешний музыкальный API (iTunes) с кэшированием в базе
- Несколько типов раундов: угадай трек, угадай исполнителя, переписанная строка (ИИ)
- Тексты песен через API lyrics.ovh
- Перефразирование строк через AI API (Groq) — опционально, с запасным алгоритмом
- Автоматическая проверка ответов с устойчивостью к опечаткам (rapidfuzz)
- Таймер и подсчёт очков за скорость
- Таблица лидеров через SQL-агрегаты
- Веб-интерфейс, адаптивный под телефон

## Технологии

Python · FastAPI · SQLAlchemy · SQLite · Jinja2 · httpx · rapidfuzz · pytest

## Как запустить

```bash
python -m venv venv
venv\Scripts\activate        # Windows
pip install -r requirements.txt
uvicorn app.main:app --reload
```

Открыть в браузере: http://127.0.0.1:8000

Документация API: http://127.0.0.1:8000/docs

## Структура

```
app/
  main.py            — FastAPI, все маршруты
  models.py          — таблицы БД (Game, Team, Track, Round, Answer)
  database.py        — подключение к базе
  schemas.py         — валидация данных
  services/
    music_api.py     — музыкальный API + кэш
    lyrics_api.py    — тексты песен
    ai_service.py    — ИИ-перефразирование (Groq) + запасной алгоритм
    rounds.py        — проверка ответов и подсчёт очков
  templates/         — HTML-страницы
  static/            — CSS
tests/               — тесты (pytest)
```

## AI-раунд (опционально)

Раунд с переписанной строкой работает и без ключа (запасной алгоритм).
Чтобы включить настоящий ИИ, получите бесплатный ключ на groq.com и задайте
переменную окружения перед запуском:

```bash
set GROQ_API_KEY=ваш_ключ       # Windows
```

## Схема базы данных

- **Game** — игра (1 ко многим с Team и Round)
- **Team** — команда
- **Track** — кэш треков из API
- **Round** — раунд (ссылается на Game и Track)
- **Answer** — ответ команды (связка «многие ко многим» между Team и Round)
